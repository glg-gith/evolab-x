\subsection{Detailed Description}
Stack of events that can occur at a given time (depending on the rate of each event) in a T\+I\+M\+E based simulation context.~\newline


E\+V\+E\+N\+T\+S \+:~\newline
 An event is an action that can be fired at any time on the S\+I\+T\+E.
\begin{DoxyItemize}
\item It has a given propensity to occur (which can change during the simulation life time)
\item It comes with an action (method) which is fired (executed) when the event occurs
\end{DoxyItemize}

\subsection*{U\+S\+A\+G\+E \+: }


\begin{DoxyItemize}
\item Instantiate
\item Push event(s) (\hyperlink{classelps_1_1_lab_event_stack_a0cf4b5b8bf78009aa20fc073f7ebfa6d}{Push\+Event()} function)
\item \hyperlink{classelps_1_1_lab_event_stack_a8335ecf33bf6210d5cb9c8d30a125f6e}{Realize\+Event()} is used to fire an event (the current time of the event stack is updated during this operation)
\begin{DoxyItemize}
\item Create a function of the form \char`\"{}double func\+\_\+name(void$\ast$ param)\char`\"{} for the update of the event's rate
\item Create a function of the form \char`\"{}double func\+\_\+name(void$\ast$ param)\char`\"{} to be executed when the event is fired
\end{DoxyItemize}
\item The events rates M\+U\+S\+T then be updated using the \hyperlink{classelps_1_1_lab_event_stack_a2c69343fc9e0218238c51004d854f900}{Update\+Stack\+Rates()} function
\end{DoxyItemize}

{\bfseries Sample \+:}~\newline
~\newline
 First of all, get yourself an event stack \+:


\begin{DoxyCode}
LabEventStack *eventStack = \textcolor{keyword}{new} LabEventStack()
\end{DoxyCode}


Secondly, define the method to be fired. This has to be done in two steps \+:
\begin{DoxyItemize}
\item The {\bfseries rate} callback
\item The {\bfseries realize} callback
\end{DoxyItemize}

~\newline



\begin{DoxyCode}
\textcolor{keywordtype}{double} MyCallbackRate(\textcolor{keywordtype}{void} *param)
\{
        cout << \textcolor{stringliteral}{"CB fired !"} << endl;
        ...
        ...                                         \textcolor{comment}{// DO SOMETHING with "param" (or not) ...}
        ...
        rate = 12.0;                                \textcolor{comment}{// Recompute the rate (constant in this ex.)}
        \textcolor{keywordflow}{return} rate;
\}
...
double MyCallbackRealize(\textcolor{keywordtype}{void} *param)
\{
        cout << \textcolor{stringliteral}{"CB fired !"} << endl;
        \textcolor{comment}{// DO SOMETHING with "param" here...}
        \textcolor{keywordflow}{return} 0.0;
\}
\end{DoxyCode}


{\bfseries Note \+:} the {\bfseries param} parameter can be any object (all you need is to cast it into the appropriate type).

Then we can create the callbacks and push them to the stack.


\begin{DoxyCode}
\textcolor{comment}{// EVENT}
...
\textcolor{comment}{// Push the event to be fired given an initial rate of 0.0.}
LabCallBack2 *rate\_callback = \textcolor{keyword}{new} LabCallBack2(MyCallbackRate);
LabCallBack2 *realize\_callback = \textcolor{keyword}{new} LabCallBack2(MyCallbackRealize);
eventStack.PushEvent(\textcolor{stringliteral}{"AN\_EVENT"}, 0.0, a\_param, rate\_callback, realize\_callback);
...
\end{DoxyCode}


Push one callback per possible event according to the needs of your simulation for the given stack.
