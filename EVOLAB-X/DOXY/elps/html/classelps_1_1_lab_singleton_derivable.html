Derivable Singleton class (Not the best because the constructor is only protected...)

USAGE :

class DerivedSingleton : public LabSingletonDerivable { public: static void initInstance() { new DerivedSingleton; // DerivedSingleton() calls LabSingletonDerivable(), which sets this as "the instance" } protected: DerivedSingleton() { } // so we can't be instantiated by outsiders ~DerivedSingleton() { } // so random strangers can't delete me };
