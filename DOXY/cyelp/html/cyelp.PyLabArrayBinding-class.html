Class PyLabArrayBinding

This class embeds a list of sites and provides features to populate it (for use in a MASS ACTION context).

All the *Array sub-classes of the simulator (See PyLabSimulatorBase) have an aggregated instance of PyLabArrayBinding (See, for example, PyLabSimulatorTimeArray.arrayBinding for an illustration of this).

USAGE :

First you will need an array based simulator :

>>> pop_max = 10000
>>> sim = PyLabSimulatorTimeArray()                         # Get yourself a simulator
>>> sim.SetMaxPopulationSize(pop_max)                       # Set the simulator's capacity

Then fill the array binding with the corresponding number of sites. The array must contain as many Sites as the simulator's capacity (10000 in the above example). For this you can use ready made ones (ex. PyLabSiteBase, ... or derivatives) and assign them manually. But, PyLabArrayBinding provides methods to ease the filling of the array from sites model objects (See PyLabArrayBinding.Populate1() and PyLabArrayBinding.Populate2()).

Another big advantage of using those methods is that it turns on the Sets Manager (See PyLabSiteSetsCalculator, ...).

The usages are pretty much same as in PyLabNetBinding.

The half-manual way :

>>> sim.arrayBinding.BeginSetSites(pop_max)                  # Mandatory to open the sites in writing
...
>>> a_site = PyLabSiteBase(sim)                              # Create a Site
>>> sim->SetOneSiteAt(a_site, 0)                             # Mandatory to assign a site to a specified location in the 
...                                                          # array (this enables the Sets Manager to monitor the Site)
...                                               
...                                                          # Repeat the above for EVERY single site
...
>>> sim.arrayBinding.EndSetSites()                           # Close the sites in writing

This allows to customize each site on the fly, but keep in mind that every single site in the array has to be assigned before closure.

The automated way :

>>> models = []
>>> a_model = PyLabSiteBase(sim)
>>> model_sites.append(a_model)                              # Do this for each different kind of site you need
...
>>> dist = [0.25, 0.75]                                      # Define a distribution (here 2 models to be spread)
>>> sim.arrayBinding.Populate1(pop_max, dist, models, True)  # Batch assignment (spread) of the sites over the network
...

Note : PyLabArrayBinding.Populate1() and PyLabArrayBinding.Populate2() take in charge everything for you. Your role is restrained to the creation of the models, and the choice of the spreading method.

Method Details

BeginSetSites(self, max_size)

 

Starts populating with a given number of sites.

WARNING : This will reset all the sets that have been set earlier. Must be call before to start adding sites with SetOneSiteAt().

Parameters:
  • max_size (int) - Maximum number of sites in the population (including empty sites).

EndSetSites(self)

 

Ends populating sites operation. Checks if all sites have been set. If not, terminates the program. All 'max_size' sites must have been set before ending. See BeginSetSites(max_size).

Populate1(self, max_size, dist, model_sites, draw_progress)

 

Populate randomly according to the given distribution and the models.

Note : dist and model_sites must be the same size.

Parameters:
  • max_size (int) - Maximum number of sites in the population (implies that all the 'max_size' sites have been instantiated before running properly the simulation)
  • dist (list) - Vector of float. Cumulative sum must be 1.0.
  • model_sites (list) - Vector of models / template sites - See PyLabSiteBase. Cumulative sum must be 1.0.
  • draw_progress (bool) - If the progress bar must be displayed while populating.

Populate2(self, max_size, dist, model_sites, draw_progress)

 

Populate with exactly the given amounts given by dist and the models.

Note : dist and model_sites must be the same size.

Parameters:
  • max_size (int) - Maximum number of sites in the population (implies that all the 'max_size' sites have been instantiated before running properly the simulation).
  • dist (list) - Vector of int. Cumulative sum must be the maximum population size.
  • model_sites (list) - Vector of models / template sites - See PyLabSiteBase. Cumulative sum must be 1.0.
  • draw_progress (bool) - If the progress bar must be displayed while populating.

SetOneSiteAt(self, a_site, node_index)

 

Adds a single site to the sets manager. A call to this function must be enclosed between BeginSetSites() and EndSetSites() calls.

WARNING : All sites must be set before ending - See EndSetSites().

Parameters:
  • a_site (PyLabSiteBase) - Site to be set.
  • node_index (int) - Index at which the Site is to be set (regarding the ordered list of this population). See also PyLabSiteSetsCalculator.GI().
