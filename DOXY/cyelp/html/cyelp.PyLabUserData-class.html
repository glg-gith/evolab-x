Class PyLabUserData

This is the base class for all the classes used for describing a Site. A Site can be completely user defined (by using PyLabUserData, a custom subclass of it, or one of the ready-made ones - See PyLabSiteBase, ...).

The related user specific information can be stored using PyLabUserData.SetData() and / or by extending PyLabUserData class (adding members).
