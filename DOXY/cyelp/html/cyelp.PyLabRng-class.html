Class PyLabRng

This class is a simplified access to Random Number Generation.

Mainly (but not only) a subset of features already available in GSL :

http://www.gnu.org/software/gsl/manual/gsl-ref.html

Parameters:
  • ralgo (int) - Can be 0, 1 or 2 (respectively : mt19937 - the default, taus, gfsr4).
