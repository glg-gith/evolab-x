Class Hierarchy

  • object: The most base type
    • cyelp.Parent
    • cyelp.PyArg: A virtual base class that defines the essential data for all arguments.
      • cyelp.PyDoubleArg: Class to define and parse a double value from the command line.
      • cyelp.PyIntArg: Class to define and parse an integer value from the command line.
      • cyelp.PyStringArg: Class to define and parse a string value from the command line.
      • cyelp.PySwitchArg: A simple switch argument.
    • cyelp.PyCmdLine: The base class that manages the command line definition and passes along the parsing to the appropriate Arg classes.
    • cyelp.PyLabArrayBinding: This class embeds a list of sites and provides features to populate it (for use in a MASS ACTION context).
    • cyelp.PyLabBinaryUtils: Utility class for writing and reading information stored in binary files.
    • cyelp.PyLabCallBack: Utility class to deal with callbacks.
    • cyelp.PyLabEventStack: Stack of events that can occur at a given time (depending on the rate of each event) in a TIME based simulation context.
    • cyelp.PyLabNetBinding: This class embeds a network (See PyLabNetwork) and provides features to populate it (for use in a SPATIALIZED context).
    • cyelp.PyLabNetwork: Main class for handling a Network (in a SPATIALIZED context).
    • cyelp.PyLabNode: The node is the base entity constituting a Network.
    • cyelp.PyLabOutputerLine: Basic implementation for output management.
    • cyelp.PyLabRng: This class is a simplified access to Random Number Generation.
    • cyelp.PyLabSet: Class implementing a Set of Big Integers.
    • cyelp.PyLabSetIter: Basic PyLabSet iterator utility.
    • cyelp.PyLabSimulatorBase: Base class meant to be subclassed when writing a simulation.
      • cyelp.PyLabSimulatorTime: A basic TIME based subclass of PyLabSimulatorBase.
        • cyelp.PyLabSimulatorTimeArray: Class designed to create MASS ACTION and TIME based simulation.
        • cyelp.PyLabSimulatorTimeNet: Class designed to create SPACE and TIME based simulation.
    • cyelp.PyLabSiteSetsCalculator: This class gives methods to deal with the "Sets" of Sites handled by the Sets Manager (See C++ LabSiteSetsManager class).
    • cyelp.PyLabTimer: Utility class for dealing with time (benchmarking).
    • cyelp.PyLabUserData: This is the base class for all the classes used for describing a Site.
      • cyelp.PyLabSiteBase: Base class for handling user defined data on a given SITE.
        • cyelp.PyLabSiteEvent: This class handles ATTRIBUTES and STATES (since it inherits from PyLabSiteBase), but also EVENTS.
    • cyelp.Py_ifstream: C++ / STL std::ifstream exposed to Python.
    • cyelp.Py_ofstream: C++ / STL std::ofstream exposed to Python.
    • cyelp.Worker
