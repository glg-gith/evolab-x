\subsection{Detailed Description}
The node is the base entity constituting a Network. Those classes have a natural hierarchy of \hyperlink{classelps_1_1_lab_network}{Lab\+Network} $>$ \hyperlink{classelps_1_1_lab_node}{Lab\+Node} $>$ \hyperlink{classelps_1_1_lab_edge}{Lab\+Edge}.

\hyperlink{class_a}{A} Py\+Lab\+Node is a node of the \hyperlink{classelps_1_1_lab_network}{Lab\+Network} (they are link between each other by edges). Each node can carry an object / site (of any kind, user is free to choose a custom representation, but it is recommended to use existing \hyperlink{classelps_1_1_lab_site_base}{Lab\+Site\+Base}, \hyperlink{classelps_1_1_lab_site_event}{Lab\+Site\+Event} or at least sub-\/classes of \hyperlink{classelps_1_1_lab_site_base}{Lab\+Site\+Base}).

\subsection*{U\+S\+A\+G\+E \+: }

\hyperlink{class_a}{A} node cannot exist without a network (See \hyperlink{classelps_1_1_lab_network}{Lab\+Network} first). Once your network is populated of nodes, each node has to be setup. There is two ways of doing this \+:

{\bfseries Manually \+:}


\begin{DoxyCode}
LabSiteBase *a\_site = \textcolor{keyword}{new} LabSiteBase(sim);         \textcolor{comment}{// Create an object to be stored in the node}
a\_node.SetUserData(a\_site);                         \textcolor{comment}{// Assign this object to the node}
\end{DoxyCode}


There is also more {\bfseries automated ways} which come with the \hyperlink{classelps_1_1_lab_net_binding}{Lab\+Net\+Binding} available via the \char`\"{}net\+Binding\char`\"{} member of all {\bfseries $\ast$\+Net} versions of the simulator (See, for example, the \hyperlink{classelps_1_1_lab_simulator_time_net}{Lab\+Simulator\+Time\+Net}). See \hyperlink{classelps_1_1_lab_net_binding}{Lab\+Net\+Binding}, for a deeper description of those methods.

Moreover those {\bfseries automated ways} give access to more advanced features (which are not available while proceeding {\bfseries manually}) \+: the Sets related features (See \hyperlink{classelps_1_1_lab_site_sets_calculator}{Lab\+Site\+Sets\+Calculator} and \hyperlink{classelps_1_1_lab_site_sets_manager}{Lab\+Site\+Sets\+Manager} for getting a full understanding of the {\bfseries Sets based} system).
