\subsection{Detailed Description}
This class gives methods to deal with the \char`\"{}\+Sets\char`\"{} of Sites handled by the {\bfseries Sets Manager} (See \hyperlink{classelps_1_1_lab_site_sets_manager}{Lab\+Site\+Sets\+Manager}).~\newline


It allows to \+:
\begin{DoxyItemize}
\item Get a set (See \hyperlink{classelps_1_1_lab_site_sets_calculator_a3a56fb6bbb50896eba98aa8ffbf56d53}{G\+S()})
\item Get a site (See \hyperlink{classelps_1_1_lab_site_sets_calculator_a4d9a4b4ee46bf9d16480a7d3ed127e55}{G\+I()})
\item Perform basic operations on the sites of a set (See \hyperlink{classelps_1_1_lab_site_sets_calculator_adea86bfd1715f7a2ec7878faa931d0bc}{A\+V\+G()}, ...)
\end{DoxyItemize}
