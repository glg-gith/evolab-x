\subsection{Detailed Description}
This class handles A\+T\+T\+R\+I\+B\+U\+T\+E\+S and S\+T\+A\+T\+E\+S (since it inherits from \hyperlink{classelps_1_1_lab_site_base}{Lab\+Site\+Base}), but also {\bfseries E\+V\+E\+N\+T\+S}.

{\bfseries Note \+:} The concept of S\+I\+T\+E (data of a node in a network -\/ S\+P\+A\+T\+I\+A\+L\+I\+Z\+E\+D context) has been kept for M\+A\+S\+S A\+C\+T\+I\+O\+N context for preserving genericity.

All the features related to A\+T\+T\+R\+I\+B\+U\+T\+E\+S and S\+T\+A\+T\+E\+S are deeply described in \hyperlink{classelps_1_1_lab_site_base}{Lab\+Site\+Base}, since \hyperlink{classelps_1_1_lab_site_event}{Lab\+Site\+Event} inherits from this class.

E\+V\+E\+N\+T\+S (See also \+: \hyperlink{classelps_1_1_lab_event_stack}{Lab\+Event\+Stack}) \+:

An event is an action that can be fired at any time on the S\+I\+T\+E (locally).


\begin{DoxyItemize}
\item It has a given propensity to occur (which can change during the simulation life time)
\item It comes with an action (method) which is fired (executed) when the event occurs
\end{DoxyItemize}

The \hyperlink{classelps_1_1_lab_site_event}{Lab\+Site\+Event} class is nothing else but an aggregate of the attributes, states and events stacks \+: See \hyperlink{classelps_1_1_lab_attributes_stack}{Lab\+Attributes\+Stack}, \hyperlink{classelps_1_1_lab_state_stack}{Lab\+State\+Stack} and \hyperlink{classelps_1_1_lab_event_stack}{Lab\+Event\+Stack}.

{\bfseries Note \+:} \hyperlink{class_a}{A} Site is {\bfseries always} related to a simulator.

\subsection*{U\+S\+A\+G\+E \+: }

\hyperlink{class_a}{A} basic use case would look like follows (assuming the setup for A\+T\+T\+R\+I\+B\+U\+T\+E\+S and S\+T\+A\+T\+E\+S has already been done -\/ See \hyperlink{classelps_1_1_lab_site_base}{Lab\+Site\+Base}) \+:

First of all define the callback methods to be fired. Those must be of the form \+:


\begin{DoxyCode}
\textcolor{keywordtype}{double} BirthRate(\hyperlink{namespaceelps_a1bd4230d698fa66dd38f0fc1cc5c2c55}{EventCallBackParam} node)                                   \textcolor{comment}{// We choose
       to pass a LabNode}
\{
        LabNode *a\_node = (LabNode *)node;
        \textcolor{keywordtype}{double} rate;
        BdmLsim4::t\_site *a\_site = BdmLsim4::GetSiteData(a\_node);               \textcolor{comment}{// Get the Site embedded in
       this node}
        rate = b * a\_site->GetAttrDouble(LabSiteBase::IND\_DEP, BdmLsim4::X);    \textcolor{comment}{// Compute the return value}
        \textcolor{keywordflow}{if}(a\_site->GetState() == BdmLsim4::MUTANT)
                rate *= 0.9;
        \textcolor{keywordflow}{return} rate;                                                            \textcolor{comment}{// return a float}
\}

\textcolor{keywordtype}{double} RealizeBirth(\hyperlink{namespaceelps_a1bd4230d698fa66dd38f0fc1cc5c2c55}{EventCallBackParam} node)
\{
        cout << \textcolor{stringliteral}{"BIRTH fired !"} << endl;
        LabNode *a\_node = (LabNode *)node;
        \textcolor{comment}{// DO SOMETHING with node here...}
        \textcolor{keywordflow}{return} 0.0;
\}
\end{DoxyCode}


{\bfseries Note \+:} the {\bfseries node} parameter can be any object (here we assume we are in a S\+P\+A\+T\+I\+A\+L\+I\+Z\+E\+D context, that's why we use the \char`\"{}node\char`\"{} term).

Then we can create the callbacks and assign them to the Site \+:


\begin{DoxyCode}
\textcolor{comment}{// EVENTS :}
\textcolor{comment}{//}
rate\_callback = \textcolor{keyword}{new} \hyperlink{namespaceelps_a121bfb217e5fbb734b95d3f7b6653fb2}{RateCallBack}(BirthRate);
realize\_callback = \textcolor{keyword}{new} \hyperlink{namespaceelps_adb49d5dbf827d9b190d0b1fd15e0193c}{RealizeCallBack}(RealizeBirth);
a\_site->PushEvent(\textcolor{stringliteral}{"BIRTH"}, 0, NULL, rate\_callback, realize\_callback);
\textcolor{comment}{//}
rate\_callback = \textcolor{keyword}{new} \hyperlink{namespaceelps_a121bfb217e5fbb734b95d3f7b6653fb2}{RateCallBack}(DeathRate);
realize\_callback = \textcolor{keyword}{new} \hyperlink{namespaceelps_adb49d5dbf827d9b190d0b1fd15e0193c}{RealizeCallBack}(RealizeDeath);
a\_site->PushEvent(\textcolor{stringliteral}{"DEATH"}, 0, NULL, rate\_callback, realize\_callback);
\textcolor{comment}{// ...}
\textcolor{comment}{// ... etc.}
\end{DoxyCode}


Push one callback per possible event according to the needs of your simulation for the given Site.
