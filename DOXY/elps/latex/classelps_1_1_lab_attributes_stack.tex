\subsection{Detailed Description}
Stack of attributes that an individual can have in an individual centered simulation context.\par
 The attributes can be defined at 3 different levels, they can concern (t\-\_\-deptype) \-:


\begin{DoxyItemize}
\item The individual
\item The site the individual lives in
\item The global/environment context
\end{DoxyItemize}

Aka \-: A \hyperlink{classelps_1_1_lab_attributes_stack}{Lab\-Attributes\-Stack} is composed of 3 stacks which can be accessed using the methods Get\-Ind\-Attributes(), Get\-Site\-Attributes() and Get\-Env\-Attributes().

U\-S\-A\-G\-E \-:


\begin{DoxyItemize}
\item Instantiate
\item Push attributes(s) (\hyperlink{classelps_1_1_lab_attributes_stack_a564a406c6bbe3c1ad056f8f85b514b9a}{Push\-Attribute()} function)
\item The attribute value (int or double) can be updated at any time and filtered by its dependency level (t\-\_\-deptype)
\end{DoxyItemize}

(in addition to events that can be fired at Site level. See \hyperlink{classelps_1_1_lab_event_stack}{Lab\-Event\-Stack} class)
