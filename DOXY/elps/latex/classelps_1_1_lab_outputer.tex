\subsection{Detailed Description}
Basic implementation for output management \-:

Basically this class provides the features to produce output of data into a file, the standard output, or both. It manipulates D\-A\-T\-A\-S\-E\-Ts (sets of data) which are simple matrixes of doubles.

D\-A\-T\-A\-S\-E\-T \-:\par

\begin{DoxyItemize}
\item Each set of data is expressed as a list of list of doubles
\item Each time the set of data is written, it is cleared (waiting to be filled again with the next data). It behaves as a buffer.
\end{DoxyItemize}

We also can customize the header and footer (\hyperlink{classelps_1_1_lab_outputer_a3fce40affff7539f6d59768830fd4e03}{Set\-Header()}, \hyperlink{classelps_1_1_lab_outputer_a03a665502df3322215595a35e624cb85}{Set\-Footer()}) of the output as well as write free entries on the fly (\hyperlink{classelps_1_1_lab_outputer_a21ecad21d95ea286a717a5ec029ee299}{Insert\-Text()} -\/ in this case the text is inserted immediately, unlike D\-A\-T\-S\-E\-T which are buffered until asked for writing).

\subsection*{U\-S\-A\-G\-E \-:}


\begin{DoxyItemize}
\item Instantiate
\item Set the associated file (only required if planned to write into files)
\item Set the separator (which will be used to separate the data of a column)
\item Define the mode of output (\hyperlink{classelps_1_1_lab_outputer_a6af708654be42ff33dcc71816656ad9f}{Set\-Ouput\-Mode()})
\item Buffer some data lines (\hyperlink{classelps_1_1_lab_outputer_a41353b7d293c1902b531eead2a31c644}{Add\-Data\-Line()})
\item Ask for writing the current set of data at your convenience (\hyperlink{classelps_1_1_lab_outputer_a53cc31c61d5fe48be47e3eaa9ee505cf}{Write\-Data()})
\item Or insert some text on the fly (\hyperlink{classelps_1_1_lab_outputer_a21ecad21d95ea286a717a5ec029ee299}{Insert\-Text()})
\end{DoxyItemize}

{\bfseries Note \-:} The \char`\"{}statistics\char`\"{} and \char`\"{}histogram\char`\"{} features are not yet implemented.
