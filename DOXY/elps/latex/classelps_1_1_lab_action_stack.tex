\subsection{Detailed Description}
Stack of events that can be fired during the simulation at any time in a global context (the user is free to determine what has to be done -\/ it can be of any kind; aka \-: on an individual, on the entire network, ...).

U\-S\-A\-G\-E \-:


\begin{DoxyItemize}
\item Instantiate
\item Push action(s) to be fired (\hyperlink{classelps_1_1_lab_action_stack_a8ae2fb5ea16320aeb6dd5c8910d8cb3d}{Push\-Timeout\-Action()}, \hyperlink{classelps_1_1_lab_action_stack_a45fe60594dfa9b74e2746c9b40a47260}{Push\-Interval\-Action()} functions) \begin{DoxyVerb}          * Create a function of the form "double func_name(void* param)"
            to be executed when the action is fired
\end{DoxyVerb}

\end{DoxyItemize}


\begin{DoxyItemize}
\item \hyperlink{classelps_1_1_lab_action_stack_a639ffa50c74766caa54f8bd243707bf3}{Try\-Fire()} action(s) recurrently (or not) in the simulation loop (This also updates the current time of the stack, at first)
\end{DoxyItemize}

(Those events/actions come in addition to events that can be fired at Site level. See \hyperlink{classelps_1_1_lab_event_stack}{Lab\-Event\-Stack} class).
