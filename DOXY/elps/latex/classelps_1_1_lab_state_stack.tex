\subsection{Detailed Description}
S\+T\+A\+T\+E \+:~\newline
 \hyperlink{class_a}{A} state is \+:
\begin{DoxyItemize}
\item Expressed as an integer value (which should be U\+N\+I\+Q\+U\+E for each one)
\item They can be linked to each other (by giving the id of the next state coming after the current one)
\item They can have a limited life time -\/ optional timeout -\/ before returning to another specified state
\item They can be forced to a specified value at any time
\end{DoxyItemize}

U\+S\+A\+G\+E \+:


\begin{DoxyItemize}
\item Instantiate
\item Push state(s) (\hyperlink{classelps_1_1_lab_state_stack_a5d2279b5bf25fd3e3628c6d35f94b7e3}{Push\+State()} function)
\item The state can be forced (\hyperlink{classelps_1_1_lab_state_stack_a561bf5cbe60e344444b78707edcbd284}{Set\+Current\+State()}), or shifted (\hyperlink{classelps_1_1_lab_state_stack_a908bdb7c1aaf4b6daa7ba5bebc6ebf8b}{Goto\+Next\+State()})
\item The timeout of the current state M\+U\+S\+T be recurrently checked to take effect (\hyperlink{classelps_1_1_lab_state_stack_aef1a38c4d79b29448e7c89886b1c01ac}{Try\+Do\+Timeout()}) 
\end{DoxyItemize}
