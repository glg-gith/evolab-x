\subsection{Detailed Description}
Class implementing a {\bfseries Set of Big Integers}.

{\bfseries Note \+:} The set is sorted in {\bfseries ascendant} order.

\subsection*{U\+S\+A\+G\+E \+: }


\begin{DoxyCode}
\hyperlink{classelps_1_1_lab_set_aea6526eace0dcc7acdd5805b0b4534f7}{LabSet} a\_set = \hyperlink{classelps_1_1_lab_set_aea6526eace0dcc7acdd5805b0b4534f7}{LabSet}(100);          \textcolor{comment}{// Get yourself a set which can contain numbers}
...                                  \textcolor{comment}{// in range [0..100] (100 excluded).}
a\_set.Set(11)                        \textcolor{comment}{// Add number '11' to the set}
a\_set.Set(84)                        \textcolor{comment}{// Add number '84' to the set}
a\_set.Print()                        \textcolor{comment}{// Display it}
...                                  \textcolor{comment}{// Shows : "\{ 11 84 \}"}
\end{DoxyCode}


{\bfseries Note \+:} You can iterate through a Set by using a \hyperlink{classelps_1_1_lab_set_1_1iter}{Lab\+Set\+::iter}.
