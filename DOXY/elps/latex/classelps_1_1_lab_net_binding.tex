\subsection{Detailed Description}
This class embeds a network (See \hyperlink{classelps_1_1_lab_network}{Lab\-Network}) and provides features to populate it (for use in a {\bfseries S\-P\-A\-T\-I\-A\-L\-I\-Z\-E\-D} context). As well as short access features to backup and restore the network (using text formatted files).

All the {\bfseries $\ast$\-Net} sub-\/classes of the simulator (See \hyperlink{classelps_1_1_lab_simulator_base}{Lab\-Simulator\-Base}) also inherit from \hyperlink{classelps_1_1_lab_net_binding}{Lab\-Net\-Binding} (See, for example, \hyperlink{classelps_1_1_lab_simulator_time_net}{Lab\-Simulator\-Time\-Net} for an illustration of this).

\subsection*{U\-S\-A\-G\-E \-:}

First you will need a network and a simulator \-:


\begin{DoxyCode}
\textcolor{keywordtype}{int} pop\_max = 10000;
LabNetwork *net = \textcolor{keyword}{new} LabNetwork();                      \textcolor{comment}{// Get yourself a
       network}
net.Populate(pop\_max);                                   \textcolor{comment}{// Populate the
       network with nodes}
...
LabSimulatorTimeNet *sim = \textcolor{keyword}{new} LabSimulatorTimeNet();    \textcolor{comment}{// Get yourself a
       simulator}
sim.SetMaxPopulationSize(pop\_max);                       \textcolor{comment}{// Set the simulator's
       capacity}
sim.netBinding.SetNetwork(net);                          \textcolor{comment}{// Assign the network
       to the simulator}
\end{DoxyCode}


Then, as explained in \hyperlink{classelps_1_1_lab_node}{Lab\-Node}, you'll need object(s) representing each Site. Each node needs a Site. For this you can use ready made ones (ex. \hyperlink{classelps_1_1_lab_site_base}{Lab\-Site\-Base}, ... or derivatives) and assign them manually (See \hyperlink{classelps_1_1_lab_node_a7dcde91224efa2813660f8b8d967bf0f}{Lab\-Node\-::\-Set\-User\-Data()}). But, \hyperlink{classelps_1_1_lab_net_binding}{Lab\-Net\-Binding} provides methods to ease the assignment of {\bfseries sites model objects} to the nodes (See Lab\-Net\-Binding\-::\-Populate() functions).

Another big advantage of using those methods is that it turns on the {\bfseries Sets Manager} (See \hyperlink{classelps_1_1_lab_site_sets_calculator}{Lab\-Site\-Sets\-Calculator}, \hyperlink{classelps_1_1_lab_site_sets_manager}{Lab\-Site\-Sets\-Manager}...).

{\bfseries The half-\/manual way \-:}


\begin{DoxyCode}
sim->BeginSetSites();                                     \textcolor{comment}{// Mandatory to open
       the sites in writing}
...
LabSiteEvent *a\_site = \textcolor{keyword}{new} LabSiteEvent(sim, a\_node);     \textcolor{comment}{// Create a Site}
sim->SetOneSiteAt(a\_site, a\_node.GetIndex());             \textcolor{comment}{// Mandatory to
       assign a site to a node}
...                                                       \textcolor{comment}{// (this enables the
       Sets Manager to monitor the Site)}
...
...                                                       \textcolor{comment}{// Repeat the above
       for EVERY single site}
...
sim->EndSetSites();                                       \textcolor{comment}{// Close the sites in
       writing}
\end{DoxyCode}


This allows to customize each node on the fly, but keep in mind that every single node has to be assigned before closure.

{\bfseries The automated way \-:}


\begin{DoxyCode}
vector<LabSiteEvent *> models;
LabSiteEvent *a\_model = \textcolor{keyword}{new} LabSiteEvent(sim);
model\_sites.push\_back(a\_model);                           \textcolor{comment}{// Do this for each
       different kind of site you need}
...
double d[] = \{0.2, 0.8\};                                  \textcolor{comment}{// Define a
       distribution (here 2 models to be spread)}
vector<double> dist(d, d + \textcolor{keyword}{sizeof}(d) / \textcolor{keyword}{sizeof}(\textcolor{keywordtype}{double}) );
sim->Populate(dist, model\_sites, \textcolor{keyword}{true});                   \textcolor{comment}{// Batch assignment
       (spread) of the sites over the network}
\end{DoxyCode}


{\bfseries Note \-:} Lab\-Net\-Binding\-::\-Populate() functions take in charge everything for you. Your role is restrained to the creation of the models, and the choice of the spreading method.
