\subsection{Detailed Description}
A basic {\bfseries T\-I\-M\-E based} subclass of \hyperlink{classelps_1_1_lab_simulator_base}{Lab\-Simulator\-Base}.

By default the time evolves continuously as follows \-: \begin{DoxyVerb}    t += -log(p) / ter
    where "p" is a random float number [0.0, 1.0] and "ter" is the current total event rate.
\end{DoxyVerb}


The way the time is computed / evolves can be customized by overriding the hook \hyperlink{classelps_1_1_lab_simulator_time_a5f3478468090fe5d741759a8806a6abf}{Time\-Step()} (See \hyperlink{classelps_1_1_lab_simulator_time_a5f3478468090fe5d741759a8806a6abf}{Lab\-Simulator\-Time\-::\-Time\-Step()} for more details).

This class comes with additional dedicated hooks to be overridden. (See \hyperlink{classelps_1_1_lab_simulator_time_ad2f79a788d88d06558e17ce65a89f769}{Reset\-Time()}, \hyperlink{classelps_1_1_lab_simulator_time_a5f3478468090fe5d741759a8806a6abf}{Time\-Step()}, \hyperlink{classelps_1_1_lab_simulator_time_a6ed55e9c17248459dfa5c6ab9caee7f5}{Fire\-Event()}, ... for an exhaustive list).

{\bfseries Note \-:} \begin{DoxyVerb}    We will often use the term "event(s) rate(s)" in time based contexts,
    since this class provides a canvas for firing events accordingly to time during
    the simulation. By default in LabSimulatorTime, the events are fired relatively
    to their rate (or propensity to occur).
\end{DoxyVerb}


Of course, the default event based behavior of this class can be customized by overriding the appropriate hooks.

\subsection*{S\-P\-E\-C\-I\-F\-I\-C\-I\-T\-I\-E\-S \-:}

The default inner code of \hyperlink{classelps_1_1_lab_simulator_time_a9cf1c9a315d192ea8c065389788fd2c5}{Run\-Simulation()} is an override of the \hyperlink{classelps_1_1_lab_simulator_base_ab48e943c2b85b25ff96b2aab4d9aa4bd}{Lab\-Simulator\-Base\-::\-Run\-Simulation()} hook.

This hook can be overridden, but by default it consists in a re-\/implementation of \hyperlink{classelps_1_1_lab_simulator_base_ab48e943c2b85b25ff96b2aab4d9aa4bd}{Lab\-Simulator\-Base\-::\-Run\-Simulation()} for the need of a T\-I\-M\-E based process.

The only differences with base version are \-:


\begin{DoxyItemize}
\item We add a reset of the time properties (\hyperlink{classelps_1_1_lab_simulator_time_ad2f79a788d88d06558e17ce65a89f769}{Reset\-Time()}) each time we call a new run (right after the \hyperlink{classelps_1_1_lab_simulator_base_aa14aa05df8173ffd2a2e67aa25f3cea5}{Init\-Simulation()} call)
\item This method is no more responsible for managing the output, since \hyperlink{classelps_1_1_lab_simulator_time_ad8845591018d7d9bdf38932faa2a04dd}{Step\-Simulation()} is
