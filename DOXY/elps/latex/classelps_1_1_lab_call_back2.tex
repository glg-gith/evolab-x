\subsection{Detailed Description}
Utility class to deal with callbacks.\par
 (Non templatized version of \hyperlink{classelps_1_1_lab_call_back3}{Lab\-Call\-Back3} for ease of use with Cython).

This version of \hyperlink{classelps_1_1_lab_call_back}{Lab\-Call\-Back} obey to the following pattern \-: \begin{DoxyVerb}    double (*method)(void* parameter)
\end{DoxyVerb}


That is to say that it returns a double and nothing else. Return 0.\-0 if you do not need to return anything...

\subsection*{U\-S\-A\-G\-E \-:}

First of all define the callback methods to be fired \-:


\begin{DoxyCode}
\textcolor{keywordtype}{double} MyMethod(\textcolor{keywordtype}{void} *a\_param)
\{
        \textcolor{comment}{// ...}
        \textcolor{keywordtype}{double} rate = a\_param * 2.0;                 \textcolor{comment}{// Do something with
       "a\_param" (can be any object)}
        \textcolor{comment}{// ...}
        \textcolor{keywordflow}{return} rate;                                 \textcolor{comment}{// Return a float}
\}
\end{DoxyCode}


Then we can create the callback \-:


\begin{DoxyCode}
LabCallBack2 *my\_callback = \textcolor{keyword}{new} LabCallBack2(MyMethod);
\end{DoxyCode}


And call it later on \-:


\begin{DoxyCode}
cout << my\_callback.execute(25.0) << endl;        \textcolor{comment}{// Writes : 50.0}
\end{DoxyCode}
