\subsection{Detailed Description}
Those classes have a natural hierarchy of \hyperlink{classelps_1_1_lab_network}{Lab\+Network} $>$ \hyperlink{classelps_1_1_lab_node}{Lab\+Node} $>$ \hyperlink{classelps_1_1_lab_edge}{Lab\+Edge}.~\newline
 That means you probably should not be doing something with nodes unless they already belong to a network, and you probably shouldn't be handling edges unless they already belong to at least one node (and a network).

There are many ways you can construct a network, but they fall into two categories\+: automated (and probably randomized) and manual.

\subsection*{U\+S\+A\+G\+E \+: }

Start out by getting yourself a network \+:


\begin{DoxyCode}
LabNetwork my\_network(\textcolor{stringliteral}{"name"}, \textcolor{keyword}{false});    \textcolor{comment}{// "name" is any string you want, and "false"}
                                         \textcolor{comment}{// means network is undirected (true = directed).}
\end{DoxyCode}


If you want to automate the construction \+:


\begin{DoxyCode}
my\_network.Populate(10000);              \textcolor{comment}{// Add 10^4 nodes to the network.}
my\_network.RandConnectPoisson(4);        \textcolor{comment}{// Connect the nodes using a Poisson(4) degree}
                                         \textcolor{comment}{// distribution and get rid of self-loops and}
                                         \textcolor{comment}{// multi-edges (done automatically).}
\end{DoxyCode}

Migrates the given fraction of Nodes in the network by rearranging their Edges.~\newline
~\newline
 Algorithm details \+:~\newline
 At each call (period), (fraction\+\_\+to\+\_\+migrate $\ast$ 100) \% of all nodes \char`\"{}migrate\char`\"{}. \hyperlink{class_a}{A} different group is randomly selected each period. If a nodes is in the migrating group, all of its edges are broken; this means the node's neighbors also end up with at least one broken edge. These broken edges (\char`\"{}stubs\char`\"{}) are then randomly reconnected. The reconnection process will make sure that no self-\/loops or parallel edges get created (it's possible that additional edges will get shuffled in order to get rid of these).
