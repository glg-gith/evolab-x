\subsection{Detailed Description}
This class handles lists of \hyperlink{class_t_c_l_a_p_1_1_arg}{Arg}'s that are to be X\-O\-R'd on the command line. This is used by \hyperlink{class_t_c_l_a_p_1_1_cmd_line}{Cmd\-Line} and you shouldn't ever use it.
