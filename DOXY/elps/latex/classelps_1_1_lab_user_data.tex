\subsection{Detailed Description}
This is the base class for all the classes used for describing a Site. A Site can be completely user defined (by using \hyperlink{classelps_1_1_lab_user_data}{Lab\-User\-Data}, a custom subclass of it, or one of the ready-\/made ones -\/ See \hyperlink{classelps_1_1_lab_site_base}{Lab\-Site\-Base}, ...).

The related user specific information can be stored using Lab\-User\-Data\-::\-Set\-Data() and / or by extending \hyperlink{classelps_1_1_lab_user_data}{Lab\-User\-Data} class (adding members).
