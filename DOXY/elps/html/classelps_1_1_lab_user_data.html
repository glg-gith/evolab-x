Detailed Description

This is the base class for all the classes used for describing a Site. A Site can be completely user defined (by using LabUserData, a custom subclass of it, or one of the ready-made ones - See LabSiteBase, ...).

The related user specific information can be stored using LabUserData::SetData() and / or by extending LabUserData class (adding members).
