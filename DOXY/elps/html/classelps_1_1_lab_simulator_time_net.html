Detailed Description

Class designed to create SPACE and TIME based simulation. It's got all the features of a LabSimulatorTime simulation but additionally aggregates a network (See LabNetwork) via the LabNetBinding inheritance.

COMMON USAGE :

  • Create a subclass of LabSimulatorTimeNet
  • Feel free to override the hooks (virtual) functions fitting your needs
