Member Function Documentation

vector<LabSiteBase *> elps::LabSimulatorDiffEqEventInd::CreateSystem ( int  critical_size)

Instantiate "critical_size" objects of type LabSiteBase. Each of them subscribes to the LabSiteSetsManager belonging to the "pop_name" set/group. Each of them is also created with a default "EMPTY" STATE. It belongs to the user to then initialize the whole population (adding some states and attributes to some of those SITEs).

Parameters
critical_sizeThe maximum critical size of the population (limit for the possibility of reproduction)
pop_nameName of the newly created group of sites (aka : population)
Returns
