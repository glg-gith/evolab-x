Detailed Description

This class embeds a network (See LabNetwork) and provides features to populate it (for use in a SPATIALIZED context). As well as short access features to backup and restore the network (using text formatted files).

All the *Net sub-classes of the simulator (See LabSimulatorBase) also inherit from LabNetBinding (See, for example, LabSimulatorTimeNet for an illustration of this).

USAGE :

First you will need a network and a simulator :

int pop_max = 10000;
LabNetwork *net = new LabNetwork(); // Get yourself a network
net.Populate(pop_max); // Populate the network with nodes
...
LabSimulatorTimeNet *sim = new LabSimulatorTimeNet(); // Get yourself a simulator
sim.SetMaxPopulationSize(pop_max); // Set the simulator's capacity
sim.netBinding.SetNetwork(net); // Assign the network to the simulator

Then, as explained in LabNode, you'll need object(s) representing each Site. Each node needs a Site. For this you can use ready made ones (ex. LabSiteBase, ... or derivatives) and assign them manually (See LabNode::SetUserData()). But, LabNetBinding provides methods to ease the assignment of sites model objects to the nodes (See LabNetBinding::Populate() functions).

Another big advantage of using those methods is that it turns on the Sets Manager (See LabSiteSetsCalculator, LabSiteSetsManager...).

The half-manual way :

sim->BeginSetSites(); // Mandatory to open the sites in writing
...
LabSiteEvent *a_site = new LabSiteEvent(sim, a_node); // Create a Site
sim->SetOneSiteAt(a_site, a_node.GetIndex()); // Mandatory to assign a site to a node
... // (this enables the Sets Manager to monitor the Site)
...
... // Repeat the above for EVERY single site
...
sim->EndSetSites(); // Close the sites in writing

This allows to customize each node on the fly, but keep in mind that every single node has to be assigned before closure.

The automated way :

vector<LabSiteEvent *> models;
LabSiteEvent *a_model = new LabSiteEvent(sim);
model_sites.push_back(a_model); // Do this for each different kind of site you need
...
double d[] = {0.2, 0.8}; // Define a distribution (here 2 models to be spread)
vector<double> dist(d, d + sizeof(d) / sizeof(double) );
sim->Populate(dist, model_sites, true); // Batch assignment (spread) of the sites over the network

Note : LabNetBinding::Populate() functions take in charge everything for you. Your role is restrained to the creation of the models, and the choice of the spreading method.

void elps::LabNetBinding::BeginSetSites ( )

Starts populating with a given number of sites. WARNING : This will reset all the sets that have been set earlier. Must be called before to start adding sites with SetOneSiteAt().

void elps::LabNetBinding::EndSetSites ( )

Ends populating sites operation. Checks if all sites have been set. If not, terminates the program. All network's sites must have been set before ending.
