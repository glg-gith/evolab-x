Detailed Description

Class designed to create SPACE based simulation. It's got all the features of a LabSimulatorBase simulation but additionally aggregates a network (See LabNetwork) via the LabNetBinding inheritance.

COMMON USAGE :

  • Create a subclass of LabSimulatorNet
  • Feel free to override the hooks (virtual) functions fitting your needs
