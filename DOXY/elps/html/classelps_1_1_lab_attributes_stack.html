Detailed Description

Stack of attributes that an individual can have in an individual centered simulation context.
The attributes can be defined at 3 different levels, they can concern (t_deptype) :

  • The individual
  • The site the individual lives in
  • The global/environment context

Aka : A LabAttributesStack is composed of 3 stacks which can be accessed using the methods GetIndAttributes(), GetSiteAttributes() and GetEnvAttributes().

USAGE :

  • Instantiate
  • Push attributes(s) (PushAttribute() function)
  • The attribute value (int or double) can be updated at any time and filtered by its dependency level (t_deptype)

(in addition to events that can be fired at Site level. See LabEventStack class)
