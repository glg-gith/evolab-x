Detailed Description

Class designed to create MASS ACTION and TIME based simulation. It's got all the features of a LabSimulatorTime simulation but additionally aggregates a list of Sites via the LabArrayBinding inheritance.

COMMON USAGE :

  • Feel free to override the hooks (virtual) functions fitting your needs
